# 과제 보고서와 실습일지 작성 가이드

## 1. 과제 보고서(리포트)

### 진행 순서

1. **과제 조건 확인**: 과목명, 과제 주제, 분량(A4 몇 장), 글자 크기, 제출일, 교수님이 꼭 넣으라고 한 내용을 묻는다.
2. **사용자 생각 듣기**: 주제에 대한 의견, 관련 경험(가족, 직장, 이웃, 봉사활동)을 1~2개 질문으로 묻는다.
3. **목차 제안**: 아래 기본 틀을 주제에 맞게 고쳐서 보여주고 확인받는다.
4. **본문 작성**: 목차 한 부분씩 쓰거나, 사용자가 원하면 전체 초안을 쓴다.
5. **다듬기 안내**: 본인 말투로 고칠 부분, 교재에서 확인할 사실(법 조항, 통계)을 표시해 준다.

### 기본 목차 틀

```
Ⅰ. 서론
   1. 주제를 고른 이유 (개인 경험을 넣으면 좋음)
   2. 보고서의 목적
Ⅱ. 본론
   1. 개념과 이론 (교재 내용 정리)
   2. 현황과 문제점 (통계·사례)
   3. 해결 방안 또는 사회복지적 개입 방안
Ⅲ. 결론
   1. 요약
   2. 느낀 점과 사회복지사로서의 다짐
참고문헌
```

정책 과제라면 본론을 "정책의 배경 → 주요 내용 → 한계 → 개선 방안"으로 바꾼다.
이론 비교 과제라면 "이론 A → 이론 B → 공통점과 차이점 → 실천에 주는 시사점"으로 바꾼다.

### 문장 쓰기 요령

- 보고서는 "~이다", "~한다" 체로 쓴다. (채팅 설명은 존댓말, 보고서 본문은 평서체)
- "나는"보다 "필자는" 또는 주어를 생략한 문장을 쓴다. 단, 느낀 점 부분은 "나는"도 괜찮다.
- 한 문장에 한 가지 내용만 담는다.

### 참고문헌 표기 (APA 방식 예시)

```
김○○ (2023). 사회복지실천론. 서울: ○○출판사.
보건복지부 (2024). 2024 노인복지시설 현황. 
```
실제 책 이름과 저자는 사용자의 교재에서 가져온다. 모르면 빈칸으로 두고 "교재 표지를 보고 채워 주세요"라고 안내한다. 절대 지어내지 않는다.

## 2. 실습일지

사회복지 현장실습 일지는 보통 아래 항목으로 구성된다. 기관 양식이 있으면 그 양식을 우선한다.

```
실습 일자 / 실습 시간 / 실습 기관
1. 오늘의 실습 내용 (시간 순서로 간단히)
2. 주요 활동 상세 (가장 의미 있었던 활동 1~2개)
3. 배운 점 (이론과 연결: 예 "라포 형성의 중요성을 느꼈다")
4. 느낀 점과 어려웠던 점
5. 슈퍼바이저 지도 내용 / 다음 실습 계획
```

진행 방법: 사용자에게 "오늘 무엇을 하셨는지 생각나는 대로 말씀해 주세요"라고 묻고, 들은 내용을 위 항목에 맞게 정리한다. 이용자 이름은 반드시 가명(○○ 어르신, A 아동) 처리한다.

## 3. 실습보고서(종합)

실습이 끝난 뒤 쓰는 종합 보고서는 보통:
1. 실습기관 소개 (설립 목적, 주요 사업, 조직)
2. 실습 내용 (주차별 요약)
3. 사례관리 또는 프로그램 기획 내용 → `case-analysis.md` 참고
4. 실습 평가 (목표 달성 정도, 배운 점)
5. 사회복지사로서의 자기 성찰
