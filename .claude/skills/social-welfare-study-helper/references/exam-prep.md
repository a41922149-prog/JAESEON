# 시험 대비 가이드

## 진행 순서

1. **시험 정보 확인**: 과목, 시험 범위(몇 주차까지, 교재 몇 장), 시험 형식(객관식, 서술형, 오픈북), 남은 기간.
2. **공부 계획**: 남은 기간이 일주일 이상이면 하루 단위 계획표를 제안한다. 하루 1~2시간, 무리하지 않는 분량으로. 꾸준함이 몰아치기보다 기억에 오래 남는다.
3. **핵심 정리**: `core-concepts.md`의 강의 노트 정리 형식으로 범위를 요약한다.
4. **문제 풀기**: 아래 형식으로 문제를 만든다.
5. **틀린 문제 복습**: 틀린 이유를 함께 짚고, 비슷한 문제를 하나 더 낸다.

## 문제 만들기

### 객관식 (5지선다, 사회복지사 시험 형식)

```
문제 1. 에릭슨의 심리사회적 발달단계 중 노년기의 발달 과업은?
① 친밀감 대 고립감
② 생산성 대 침체
③ 자아통합 대 절망
④ 근면성 대 열등감
⑤ 정체성 대 역할혼란
```

- 문제를 한꺼번에 주고, **정답과 해설은 사용자가 답을 말한 뒤에** 알려준다. 스스로 떠올려 보는 과정이 기억을 단단하게 만든다.
- 사용자가 "정답도 같이"라고 하면 문제 아래에 정답과 해설을 바로 붙인다.
- 해설은 "왜 정답인지" + "나머지 보기는 어느 단계인지"까지 짚는다.

### 서술형

```
문제. 강점 관점과 병리 관점의 차이를 설명하고, 노인 사례에 적용하시오. (20점)
```
답안 쓰는 요령을 같이 알려준다:
- 첫 문장에 핵심 정의
- 비교는 표나 "첫째, 둘째"로 정리
- 사례 적용 부분에서 점수가 갈린다
- 마지막에 사회복지적 시사점 한 문장

사용자가 직접 쓴 답안을 주면 채점 기준(정의, 비교, 적용, 구성)으로 피드백하고 보완한 모범 답안을 보여준다.

## 외우기 요령

나이가 들면 외우기 어렵다고 걱정하는 경우가 많다. 이해와 연결을 통한 기억이 오히려 더 오래 간다고 격려하고 아래 방법을 제안한다.

- **앞 글자 따기**: 예) 비에스텍의 관계 원칙 7가지 — 개별화, 의도적 감정표현, 통제된 정서적 관여, 수용, 비심판적 태도, 자기결정, 비밀보장
- **내 경험에 붙이기**: 에릭슨 단계를 본인과 가족의 나이대에 대입
- **소리 내어 설명하기**: 배운 내용을 가족이나 친구에게 설명해 보기
- **짧게 자주**: 하루 20분씩 세 번이 한 시간 한 번보다 낫다
