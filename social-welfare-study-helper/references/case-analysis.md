# 사례 분석 가이드

사례 분석 과제는 "이 사람에게 무슨 일이 있고, 왜 그런지, 어떻게 도울지"를 이론에 기대어 설명하는 작업이다.

## 진행 순서

1. **사례 받기**: 교수님이 준 사례인지, 실습/개인 경험 사례인지 확인한다. 개인 사례라면 가명 처리를 안내한다.
2. **분석 관점 확인**: 과제에서 지정한 이론이 있는지 묻는다. 없으면 생태체계 관점 + 강점 관점을 기본으로 제안한다.
3. **아래 틀로 정리**하고, 각 칸에 사례의 어떤 내용이 들어가는지 보여준다.

## 기본 틀: 사회복지실천 과정

```
1. 사례 개요
   - 클라이언트 기본 정보 (가명, 나이, 성별, 가족 구성)
   - 의뢰 경위 / 주 호소 문제 (본인이 가장 힘들다고 말하는 것)

2. 사정 (assessment)
   - 개인 차원: 신체 건강, 심리·정서, 경제 상황
   - 가족 차원: 가계도(genogram) 설명, 가족 관계
   - 환경 차원: 생태도(eco-map) 설명 — 이웃, 기관, 종교, 직장 등과의 연결
   - 강점과 자원: 본인의 능력, 지지해 주는 사람, 이용 가능한 제도

3. 문제 규정과 목표 설정
   - 우선순위가 높은 문제 2~3개
   - 장기 목표 / 단기 목표 (구체적이고 측정 가능하게)

4. 개입 계획
   - 직접 개입: 상담, 정서 지지, 교육
   - 간접 개입: 자원 연결(기초생활보장, 장기요양, 바우처 등), 지역사회 연계
   - 누가, 언제, 무엇을

5. 평가와 종결 계획
   - 목표 달성을 어떻게 확인할지

6. 사회복지사로서의 소감 / 윤리적 고려 사항
```

## 자주 쓰는 관점과 쉬운 설명

- **생태체계 관점**: 사람은 가족·이웃·제도와 서로 영향을 주고받는다. 문제를 개인 탓이 아니라 "사람과 환경 사이의 맞지 않음"으로 본다.
  - 미시체계(가족, 친구) → 중간체계(미시체계끼리의 관계) → 외체계(직장, 지역 기관) → 거시체계(법, 문화, 정책)
- **강점 관점**: 문제보다 그 사람이 가진 힘과 자원에 주목한다. "무엇이 부족한가" 대신 "무엇을 해냈고, 누가 곁에 있는가"를 묻는다.
- **임파워먼트 관점**: 클라이언트가 스스로 결정하고 힘을 되찾도록 돕는다.
- **위기개입 모델**: 갑작스러운 사건(사별, 실직, 재난) 직후 단기간 집중 개입.
- **인지행동 모델**: 생각(인지)을 바꾸면 감정과 행동이 바뀐다.
- **해결중심 모델**: 문제 원인보다 "이미 잘 되고 있는 것"과 예외 상황에 집중. 기적 질문, 척도 질문 사용.

## 가계도·생태도

채팅에서는 그림 대신 글로 관계를 정리해 준다. 사용자가 그림을 원하면 손으로 그리는 방법을 단계별로 안내한다.
- 가계도 기호: 남성 □, 여성 ○, 클라이언트는 겹선, 사망은 ×, 결혼은 가로선, 자녀는 아래로 내린 선
- 생태도 선: 굵은 선(강한 관계), 점선(약한 관계), 빗금 선(갈등 관계), 화살표(자원이 흐르는 방향)

## 표현 다듬기

| 피할 표현 | 권하는 표현 |
|---|---|
| 무능력하다 | 현재 ○○에 어려움을 겪고 있다 |
| 고집이 세다 | 자기 결정 의지가 뚜렷하다 |
| 문제 가정 | 여러 어려움이 겹친 가정 |
| 독거노인 | 홀로 사는 어르신 (과제에 따라 공식 용어 사용 가능) |
